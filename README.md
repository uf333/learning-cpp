# C++ 

C++ fundamentals I've been working through, plus a small calculator program.

## What's inside

- `helloworld.cpp`: an interactive hello world with user input
- `variables.cpp`: variables and data types
- `ifstatements.cpp`: if/else logic
- `loops.cpp`: for loops
- `functions.cpp`: writing and calling functions
- `calculator.cpp`: a calculator program that combines the above

## Run one

```
g++ calculator.cpp -o calculator
./calculator
```
